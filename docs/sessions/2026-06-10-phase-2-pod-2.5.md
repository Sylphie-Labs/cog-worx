# Session 2026-06-10 — Phase 2 Pod 2.5 (Recall Stack) — implementation

**Status:** IMPLEMENTED 2026-06-10. Pending spike gate (S12) + red-team pass before VALIDATED.

## Scope (per ROADMAP)

Pod 2.5 — recall stack. Dense + BM25 + graph + temporal channels → Reciprocal Rank Fusion →
rerank seam → token-budget assembly with lost-in-the-middle ordering.

## Design decisions (D1–D16)

Designed by mythos (deep-reasoning pass). Full rationale in the session conversation.

- **D1** — New package `src/cogworx/recall/` (query, results, channels, rendering, fusion, rerank, assembly, stack). Not substrate/runtime/knowledge — it is cross-store composition.
- **D2** — BM25 lives on `EntityKG` (`claims_full_text`), not `GraphStore`. Enforces the same skeleton exclusion, scope coalesce, datetime normalization, and derived-at-read confidence as all other `EntityKG` read methods.
- **D3** — Score-rank contract for BM25: implementation-defined positive score; only descending rank is contractual. Double uses real Okapi BM25 (k1=1.2, b=0.75); rank-parity (not score-equality) is tested against the Neo4j adapter.
- **D4** — `ScoredClaim.text_score: float | None = None` — additive optional field (C3 rule, `similarity` precedent). **F1 approved.**
- **D5** — Temporal channel = `EpisodeStore.recent_episodes` (newest-first, `before` filter). Episodes are a distinct corpus from claims; the temporal channel answers recency questions that extraction hasn't reached yet.
- **D6** — `RecallChannel` is a single Protocol with `can_serve` + `search`. Unservable query → `can_serve` returns False → stack records `skipped` (observably distinct from `ok, count=0`).
- **D7** — Five built-in channels: `dense.claims`, `bm25.claims`, `graph.claims`, `temporal.episodes`, `dense.latent`.
- **D8** — Validity post-filter at the channel layer (drop expired claims, `include_invalidated=False` default). Does not amend `claims_by_similarity`. **F4 approved.**
- **D9** — `RecallResult.key` is namespaced: `"claim:{id}"` / `"episode:{id}"` / `"latent:{id}"`. Cross-kind dedup is prevented by namespace prefix.
- **D10** — RRF: `score(key) = Σ 1/(60 + rank_i)`, `k_rrf=60` default (spike sensitivity-checks {20,60,120}). Deterministic tie-break `(score DESC, key ASC)`. **F6 approved.**
- **D11** — Rendering: per-kind pure functions in `rendering.py`. Claim: `"{subject} {predicate} {payload} [{epistemic_type}, conf={:.2f}, scope={scope}]"`. Episode: `"[{role} @ {datetime}] {content}"`. Latent: `payload["text"]` or `repr(payload)`.
- **D12** — Rerank seam: `Reranker` Protocol with `model_bearing: bool` structural label; `NoopReranker` default. Subset-permutation guard (`assert_rerank_subset`) enforced by `RecallStack` after every reranker call. No cross-encoder in 2.5. **F3 approved.**
- **D13** — Stack: `asyncio.gather(return_exceptions=True)` fan-out; raising channel → `failed` status, not crash (S8). Duplicate channel names rejected at construction.
- **D14** — Assembly: greedy-skip admission (skip items that individually exceed budget, continue); U-fold output (front/back alternating — best at edges, worst in middle, Liu et al. 2307.03172).
- **D15** — Scope: single `RecallQuery.scope` string; claim channels pass it through; latent/episode channels ignore it (scope governs claims only per Pod 2.4). **F5 approved.**
- **D16** — S1 as import-level invariant: `cogworx.recall` has zero imports from `cogworx.model` or `cogworx.runtime`. Enforced by a subprocess-based test in the spike.

## Spike gate (pending — S12)

**Must pass before VALIDATED.** Design by eval-stats; red-team pass required (standing rule).

Spike assertions (SC-1–SC-7):
- **SC-1** — Fused Recall@10 ≥ best single channel on the mixed fixture set (the RRF claim).
- **SC-2** — Per-type lesion sensitivity: removing the winning channel for a query type measurably drops that type's recall. Mutation-resistant: removing a non-winning channel must NOT drop that type's recall.
- **SC-3** — k_rrf sensitivity {20, 60, 120} — conclusions stable across the range.
- **SC-4** — S5 invariant: every surfaced result has ≥1 `ChannelHit` with channel name + rank.
- **SC-5** — S1 invariant: import-absence test (subprocess) + full spike runs with no `Model` instance.
- **SC-6** — Assembly U-shape + budget property suite green under randomization with fixed seed.
- **SC-7** — Scope isolation: user-scoped claims never surface under `scope="agent"` queries through any channel.

Red-team gate required before marking VALIDATED (2.0–2.4 each surfaced HIGH+ findings at this gate).
