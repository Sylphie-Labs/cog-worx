## What the corpus is for (recap)
4.4c builds the ≥210-item labeled corpus the 5 arms (A/C/C′/D/D′) run over so `youden.nested_bootstrap_delta`
can decide the **statistical half** of the Phase-4 gate: does the adversarial dialectic (D) beat the oracle
floor (A) and a neutral-trajectory control (C′) on **Youden's J** (sens+spec−1) on stratum **K**, paired-CI
above 0. Labels/strata are ground truth the model is never told.

## Prong A — External literature (cited, adversarially verified)

### A1. Label provenance — oracle/human, never an LLM judge *(high)*
RewardBench (2403.13787), JudgeBench (2410.12784): labels anchored to **objective correctness** — human-verified
chosen/rejected pairs, or verifiable reasons (failing tests, wrong facts). JudgeBench deliberately targets tasks
where "crowdsourced human preference is a poor indicator of factual/logical correctness." An LLM may be a
**secondary quality gate**, never the label-setting authority. → **Confirms plan §3 label-provenance rule.**

### A2. LLM-flag → human-adjudicate is the safe label-cleaning pattern *(high)*
"Verifying the Verifiers" (2506.13342): frontier LLMs **flag** suspect labels at scale; specialized LLM judges
filter candidates; then **five human annotators** make the final correction. LLM detects, humans decide. → New
input: we can legitimately run an **LLM noise-audit pass** over the corpus to *flag* candidate-mislabeled items
for human review without violating the no-judge-labels rule.

### A3. Clean/negative items must be POSITIVELY re-verified *(high)*
PRMBench (2501.03124) selects **completely-correct** solutions from human-annotated PRM800K — affirmative human
re-verification, not absence-of-flag. **Caveat (non-i.i.d. clean pool):** PRM800K's correct pool was gathered
via active learning biased toward "convincing-but-incorrect," so an anchored clean base is **not a uniform
sample**. → Confirms plan C1/C2 (§3); **adds** a representativeness concern the plan does not yet address.

### A4. Label noise is large and ranking-distorting *(high)*
~16% of items across 14 fact-checking benchmarks are ambiguous/mislabeled (~9.1% ambiguous + ~6.6% mislabeled),
**enough to flip model rankings** (2506.13342, COLM 2025). → A corpus-level noise audit is not optional polish;
mislabels directly corrupt the J the gate is computed on.

### A5. Planted/synthetic errors are systematically EASIER than organic — the dominant failure mode *(high)*
The strongest and most dangerous finding. Learning-based detectors hit ~90% accuracy on synthetic bugs yet
**<10% precision on real repos** (2204.10049); a large fuzzing study found **0/50 organic CVE bugs** while
synthetic bugs were findable, with "a dramatic difference between where synthetic and organic bugs live w.r.t.
the main path" (2208.11088; ResearchGate 352139614). **Performance on planted errors does not reliably transfer
to organic errors.** → Direct threat to the gate's external validity: a corpus of only LLM-planted errors can
certify a dialectic that catches easy planted errors and misses real ones. *Domain-transfer caveat: evidence is
from bug-detection/fuzzing, generalizes by analogy, not same-domain LLM-judge result.*

### A6. Mutation testing is valid but bounded — coupling ≈73% *(high)*
Just et al. FSE 2014 (357 real faults): significant correlation between mutant detection and **real**-fault
detection, independent of coverage and stronger than statement coverage — **but** the coupling effect holds for
only ~73% of real faults (17% not coupled to common operators; 10% need new/stronger operators). Papadakis
ICSE 2018 qualifier: correlation weakens controlling for test-suite **size**. → Deterministic mutation is a
defensible O-stratum injector but caps realism; mix operators, don't rely on one family.

### A7. Planted-error difficulty is a controllable knob — must calibrate & report *(high)*
BugFarm (2310.02407) mutates least-attended statements to make bugs hard-to-detect (up to +40% FN rate for
predictors). Difficulty is a **design dimension**, not a fixed property of injection — so report the planted
difficulty distribution rather than assume representativeness. *Caveat: difficulty shown is model-relative.*

### A8. Keep the error-injector independent from the system under test *(high)*
PRMBench's own flaw: GPT-4o **planted** the errors AND was one of the 15 **evaluated** critics — injector-is-also-
a-critic circularity. → Sharpens plan F3: the planter must be independent not just "a different agent" but
plausibly a **different model family** from both thesis and antithesis — open question whether different-family
is enough or a **non-LLM/deterministic** injector is needed for the O stratum.

### A9. Held-out discipline — publishing leaks, private leaderboards still overfit *(high)*
2505.18102: publishing ground truth contaminates future models; keeping it private **still** permits test-set
overfitting via feedback loops (Goodhart; Blum–Hardt "Ladder"). → Separate a **disclosed tuning subset** from a
**protected held-out measurement set**, and limit how often the measurement set is touched. The nightly cadence
is a live feedback-loop risk the plan must bound.

### A10. LLM-judge biases are real; isolate with a deterministic "tie" control set *(medium)*
Biases exist (position, length/verbosity, style/markdown, model-origin, self-preference). A **deterministically-
labeled** synthetic control set (225 pairs where an unbiased judge should say "tie": length/position/style/
model-origin) doubles as a positive/negative control (2604.23178, preprint). **Important: specific magnitudes/
rankings of biases were REFUTED in voting** (self-preference-via-perplexity 1-2; style-dominates/position-
negligible 0-3) — rely only on *existence + need to control*, never on a specific bias ranking.

### A-gaps (not surfaced with citations — covered by internal prior art instead)
- **Item 7** (label-shuffle/permutation collapse-to-chance, positive controls) — no external citation found.
- **Item 8** (paired/CRN sizing, sens-spec covariance, CI reporting) — no external citation found.
  → Both are already designed in `youden.py` (4.4a) + the Pod 2.1 stats precedent; internal prior art is the
  authority here, not the web.

### Refuted (do NOT rely on)
- "Self-preference driven by perplexity regardless of authorship" — 1-2.
- "Style bias dominates / position bias negligible" — 0-3.

  info-diet control (plan C vs D axis) and the judge-calibration harness.
- `cog-worx src/cogworx/testing/reference_dialectic.py` + the 4.3/4.4b spike kits — `PLANTED_*_THESIS` fixtures,
  `StubOracle`/`StubJudgeOracle`, paired-negative-control discipline; extend for corpus validation spikes.

**Generalize**
- `tess evals/benchmark/cases.py` + `runner.py` — minimal `BenchmarkCase`/`ScorerSpec` schema + loader → wrap in
  a `CorpusItem` carrying stratum/regime/provenance/lock metadata.
- `tess evals/datasets/generate_claim_confidence_calibration.py` — stratified synthetic generator (400 cases + 8
  hand-curated anchors, fixed seed, **regime-balanced allocation**) — template for error-regime stratification.

**Gaps — NO prior art, 4.4c builds from scratch** (and exactly where the adversarial pass will bite)
1. **Held-out / measurement-vs-tuning seam** — no corpus-locking, git-SHA pinning, or refuse-to-load-unlocked guard.
2. **Error-stratum regime taxonomy** — no corpus-level error-type catalog (tess has antithesis *severity*, not this).
3. **Jury / human adjudication protocol** — no inter-annotator-agreement mechanism for the C2 human tier.
4. **Corpus contamination audit** — no "did the tuning loop already see this item?" check.

**Cautionary:** skip `bizzy` single-store patterns (CANON divergence); `sylphie` has no corpus overlap.

## Synthesis — convergence + NEW tensions for the plan

**The research strongly RATIFIES the existing 4.4 plan on:** oracle/human-only labels (§3 ↔ A1), positive C1/C2
clean re-verification (§3 ↔ A3), stratification to avoid composition confound (§2 O/K ↔ A-stratification),
independent error-planter F3 (↔ A8), held-out split (§3 ↔ A9), frozen tests (§13.1), label-shuffle + positive
controls (§13.6/§13.4 ↔ internal), paired nested bootstrap with CIs (§4/4.4a ↔ A-gaps covered internally).

**NEW tensions the research surfaces that the current plan does NOT fully address** (planning must resolve or
explicitly defer; the adversarial pass will target these):

- **T1 — Planted-vs-organic external validity (A5, the big one).** The plan's errors are agent-planted; the
  literature says planted errors are systematically easier than organic and may not transfer. The gate could
  certify "D catches easy planted errors," not "D catches real errors." Plan has **no** organic-error holdout,
  **no** planted-difficulty calibration/reporting, **no** stated transfer caveat. Options: (a) add an organic-
  error stratum from real cog-worx run failures / a real bug corpus; (b) difficulty-calibrate planted errors and
  report the distribution; (c) accept planted-only for v1 with an explicit external-validity carry-forward.
- **T2 — Planter independence degree (A8).** F3 says "different agent than antithesis author." Research says the
  injector being the same *model family* as an evaluated critic is the PRMBench circularity. Decision: planter =
  different model **family** from thesis AND antithesis, and/or **deterministic/non-LLM** injection for the O
  stratum. Interacts with decision-#2 (D′ second family) and nightly budget.
- **T3 — Clean-pool representativeness (A3 caveat).** Positive re-verification (C1/C2) guarantees clean items are
  *correct*, not that they're *representative / difficulty-matched* to the error items. Trivially-clean items
  inflate specificity. Plan should difficulty-match clean↔error or report the clean-difficulty distribution.
- **T4 — Corpus noise audit (A2/A4).** ~16% label noise flips rankings. Add an **LLM-flag → human-adjudicate**
  noise-audit pass over the corpus (safe per A2) before it's locked. Plan has no such pass.
- **T5 — Feedback-loop overfitting on a nightly cadence (A9).** Even a held-out set overfits if hit every night.
  Need a discipline: tuning happens on the disclosed subset; the binding measurement set is touched rarely (and
  the MeasurementFingerprint §6 freshness binding helps but doesn't bound feedback-loop touches).
- **T6 — Mutation realism cap (A6/A7).** If deterministic mutation seeds the O stratum, coupling ≈73% caps real-
  fault realism; mix operators, calibrate difficulty.
- **T7 — Judge-bias control set (A10).** Optional reported-diagnostic: a deterministic "tie" control set to show
  the antithesis/judge protocol isn't merely exhibiting position/length/style/origin biases. Rely on existence
  only — bias magnitudes are unsettled.
