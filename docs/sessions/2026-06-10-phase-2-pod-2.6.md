## Design decisions (D1–D16)

Designed by mythos (deep-reasoning pass). Full rationale in the session conversation.

- **D1** — New package `src/cogworx/injection/` (`__init__`, `policy`, `injector`). Lives between `cogworx.recall` and `cogworx.runtime` in the dependency graph (runtime → injection → recall/substrate).
- **D2** — `MemoryPolicy` is a frozen Pydantic model: `token_budget`, `min_per_kind`, `required_kinds`. `DEFAULT_MEMORY_POLICY` = 2048-token budget, no floor, no required kinds.
- **D3** — `InjectedMemory` is a frozen Pydantic model carrying `context`, `status`, `missing_kinds`, `kinds_present`, `channel_status`, `latent_uses_recorded`, `record_use_error`.
- **D4** — `MemoryStatus` is a three-way `Literal["ok", "unwired", "below_floor"]`. `"unwired"` = no stack; `"below_floor"` = required kinds absent; `"ok"` = all required kinds present (or none required).
- **D5** — `MemoryInjector` takes a wired `RecallStack` at construction (required). Optional `latent_store`, `model` (duck-typed), and `clock`. Model reference is duck-typed via `getattr(model, "count_tokens", None)` — no `isinstance`, no `cogworx.model` import (S4/S8).
- **D6** — `resolve_token_counter` extracts `count_tokens` from a model object via pure duck-type; falls back to `approx_tokens` if absent or non-callable. No runtime `Model` import (S4).
- **D7** — `inject()` stamps `query.as_of` with the injected clock when the caller omits it (D14 — callers should not need to track wall time).
- **D8** — Fan-out via `RecallStack.recall()`; token counter resolved from the injected model; `assemble()` called with `policy.token_budget` and `policy.min_per_kind`. Full Pod 2.5 assembly pipeline (greedy-skip + U-fold) used unchanged.
- **D9** — `kinds_present` computed from admitted chunks; `missing_kinds` = required kinds absent from `kinds_present`. Status set to `"below_floor"` iff `missing_kinds` is non-empty.
- **D10** — `record_use` for admitted latent chunks: extract `"latent:"` prefix, call `latent_store.record_use(ids)` (best-effort, S8). Errors captured into `record_use_error`; `status` is NOT changed. CF-3 from Pod 2.5 resolved here.
- **D11** — `RunContext` gains `injector: MemoryInjector | None` and `_bound_policy: MemoryPolicy | None`. `recall()` method: explicit `policy=` arg > bound stage policy > `DEFAULT_MEMORY_POLICY`. Returns `status="unwired"` with empty context when `injector is None`.
- **D12** — `RunContext.bind_memory_policy(policy)` set by the engine before each stage; `bind_memory_policy(None)` clears it. Shared-per-drive context must not leak a prior stage's policy.
- **D13** — `StageContext` Protocol gains `recall(query, *, policy=None) -> InjectedMemory` (annotation-only import; no runtime cycle). `Stage` Protocol gains optional `memory_policy: MemoryPolicy` attribute (read via `getattr`, mirrors `retry_policy` pattern).
- **D14** — `Engine` gains `recall_stack: RecallStack | None` constructor arg. Builds `MemoryInjector(recall_stack, latent_store=latent, model=model, clock=clock)` when wired; `None` when not. Passed into `RunContext` via `_build_context`.
- **D15** — Engine reads `stage.memory_policy` via `getattr` and calls `ctx.bind_memory_policy()` before `stage.run(ctx)`; clears (binds `None`) on each iteration so no policy leaks across stages (comment in `engine.py` documents this invariant).
- **D16** — S1 invariant: `cogworx.injection` has zero runtime imports from `cogworx.model` or `cogworx.runtime`. `injector.py` uses `TYPE_CHECKING` guard. Enforced by subprocess-based test in the spike (SC-8).

## Spike gate (pending — S12)

**Must pass before VALIDATED.** Design by eval-stats; red-team pass required (standing rule).

Spike assertions (SC-1–SC-8):
- **SC-1** — S8 unwired lesion: `Engine` with `recall_stack=None` → `ctx.recall` → `status="unwired"`, empty chunks, run `COMPLETED`. Negative control: wired stack must NOT produce `"unwired"`.
- **SC-2** — Budget never exceeded (property suite over random fixtures with fixed seeds). Tokenizer seam: swapping `approx_tokens` for `len` changes which items are admitted (load-bearing counter). `resolve_token_counter` uses `model.count_tokens` when present; falls back to `approx_tokens` when absent or non-callable (S4).
- **SC-3** — Assembly floor (`min_per_kind`): with a budget and episode-dominated fixture, `min_per_kind=1` guarantees claim + latent in output; `min_per_kind=0` drops minorities under tight budget. `min_per_kind=0` output byte-identical to no-arg call (golden regression).
- **SC-4** — Verdict floor + S9: `required_kinds` absent → `status="below_floor"` + `missing_kinds` populated. Zero model calls across all SC-4 scenarios (S9: verdict is pure counting).
- **SC-5** — `record_use` admitted-only + S6 replay: admitted latent ids get +1, dropped id gets 0. Resume of a `COMPLETED` run does NOT re-call `record_use` (S6). At-least-once: two `inject()` calls → `record_use` count = 2; negative control: single call → count = 1.
- **SC-6** — Hot-first gate (CF-4 falsifier): hot sim=0.30 < τ + cold sim=0.90 > τ → cold ranked above hot. Hot sim ≥ τ fills k → cold search never called (spy counter = 0). All-hot-sub-τ fallback equals tier-agnostic global order (D10 correctness).
- **SC-7** — S5 provenance: every chunk has ≥1 `ChannelHit` with non-empty channel name and `rank ≥ 1`. `InjectedMemory.channel_status` non-empty; names match the stack's channels. Zero model calls across all SC-7 scenarios.
- **SC-8** — S1 import invariants: `cogworx.injection` imports cleanly as first import. `cogworx.recall` does NOT import `cogworx.runtime`. `cogworx.injection` has zero runtime imports from `cogworx.runtime` (TYPE_CHECKING guard verified). Known CF documented: `cogworx.recall` transitively imports `cogworx.model.base` (CF-A above).

Red-team gate required before marking VALIDATED (2.0–2.5 each surfaced HIGH+ findings at this gate).
