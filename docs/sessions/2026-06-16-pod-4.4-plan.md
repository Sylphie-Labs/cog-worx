## 0. What the gate must prove

The Phase-4 GATE has **two halves**:

1. **Statistical** — the adversarial-antithesis dialectic (arm **D**) beats both a neutral second-look
   (**C**) and the oracle-only floor (**A**) on **Youden's J** (`J = sens + spec − 1`) by ≥ Δmin, with
   a *paired* bootstrap CI entirely above 0. Explicitly **not** a single "catch-rate" number — a
   yes-machine scores 100% catch-rate and J ≈ 0, so J is the only honest statistic.
2. **Structural (S9)** — asserted as code, not statistics: routing is byte-identical under any model
   self-report (INV-1), a judge-only pass can never reach `verified` (INV-2), and no model-derived item
   ever mints a `confirmed` Claim node (INV-3). These run **live through the Engine every CI**.

## 1. Arms (resolves red-team CRITICAL-2)

> **CRITICAL-2:** as originally drafted, C (neutral) and D (adversarial) differed *only* by
> `_SYSTEM_INSTRUCTIONS` (`dialectic.py:427`) — a pure prompt swap. Billing "D>C" as a *structural* S9
> result violates S9 ("structure over prompting"). **Ruling:** make C/D differ by a **code path** — the
> **information diet** (a different `ContextRequest` construction, `dialectic.py:493`), which is already a
> first-class code-controlled seam.

| Arm | What runs | Lesion | Structural? |
|---|---|---|---|
| **A** | Oracle only (executable oracle verdict; no antithesis) | the ground-truth floor | yes (no AntithesisStage in pathway) |
| **B** | Single-pass self-check (thesis model reviews own output) | the shared-weights self-preference degenerate | partly — **reported-only strawman** |
| **C** | Neutral second-look, **final-answer-only** diet, fresh isolated instance | neutral framing + restricted diet | **yes** (restricted `ContextRequest`) |
| **D** | Adversarial antithesis, **trajectory-access** diet, fresh isolated instance (shipped 4.3 config) | the full shipped dialectic | **yes** (full `ContextRequest`) |
| **D′** | D, but **cross-family** model (antithesis ≠ thesis family) | correlated-blind-spot / shared-weights collusion (F4) | yes (different model binding) |

- The C→D structural axis is **information diet** (final-answer-only vs trajectory-access — the SIRAJ
  upgrade 4.3 shipped). D>C is allowed to claim *"adversarial framing **with trajectory access** beats a
  neutral final-answer-only second look"* — **not** "framing alone wins." The framing+diet confound is
  **bundled**; the full decomposition (a C′ = neutral+trajectory cell) is **deferred** (doubles arm count
  for a second-order question). The plan states the bundle openly.
- A and B are **reported-only** (Pod 2.1 deprecation of beating-a-weak-baseline,
  `test_pod_2_1_stats_spike.py:297-311`) **except** where A becomes binding on stratum K (§2).
- The over-flagger confound ("D>C only because D flags more") is neutralized by gating on **J** (sens +
  spec), not catch-rate: an over-flagging D loses specificity and cannot win.

## 2. The oracle-adjudicability split (resolves CRITICAL-1)

> **CRITICAL-1:** in shipped routing (`dialectic_state.py:454-472`) the antithesis's only causal lever is
> BROKE→REFINE; it can never turn a FAIL into a PASS, and a judge-pass routes to UNVERIFIABLE regardless
> (rule 6, `:468`). So on **oracle-checkable** errors, arm A is already at ceiling and D *cannot* beat it
> by Δmin — "D>A on a mixed corpus" measures the **oracle-checkable fraction of the corpus, not antithesis
> quality**. **Ruling:** split error items by oracle-adjudicability; bind the gates differently.

Adjudicability is assigned **mechanically**: an item is **O** iff a registered executable oracle returns
`is_executable ∧ valid_check` on it (`contracts.py:98-103`); else **K**. The split is oracle-determined,
not author-judged.

| Stratum | Population | Gated comparison | Reported-only |
|---|---|---|---|
| **O** (oracle-adjudicable errors) | errors an executable oracle decides | **S9 invariant** (route driven by oracle); D not-worse-than-A | D≈A (pre-registered **null**), D-vs-C |
| **K** (oracle-blind errors) | errors no shipped oracle reaches | **D > A by Δmin on J** (paired CI > 0); **D > C by Δmin on J** | D-vs-D′ gap |
| **clean** (re-verified correct) | independently re-verified correct items | the **specificity** arm of J (C and D must not over-flag) | per-arm FP rate |

- **K is the only place D>A is binding** — the sole regime where the model antithesis has a measurable
  causal contribution (A's J on K ≈ 0: the oracle produces no flag, all FN). This kills both halves of the
  corpus-composition attack: oracle-checkable errors land in O (D>A not gated → can't fail a great
  antithesis); oracle-blind errors are gated on K regardless of the O/K ratio (strata scored separately,
  never pooled).
- The **clean stratum is shared** across the O- and K-J computations (a false positive is
  stratum-of-error agnostic). eval-stats handles the induced correlation (§4).

## 3. Corpus & labeling (resolves HIGH-3)

**Label-provenance rule (non-negotiable):** every label (is-error / is-clean, and the O/K stratum) is set
by **oracle or human, NEVER by any judge/antithesis model**, and never inherited from "the run passed."

- **Error items** planted by a **different agent than the antithesis author** (F3); held-out error
  categories for measurement vs a disclosed tuning subset; answer-bearing artifacts stripped from the
  antithesis's input (tess `judge_calibration.py:149`).
- **Clean stratum cleanliness independently re-verified (HIGH-3)** — "it passed a Phase 1-3 run" means
  "wasn't caught," not "correct" (repo precedent: the Pod 2.1 silently-anti-conservative gate, the 155
  latent mypy errors). A latent-error item mislabeled clean turns a *good* D that flags it into a scored
  false-positive → punishes the better antithesis. Two tiers, both require *positive* re-verification:
  - **C1 (oracle-re-verified):** oracle returns `holds ∧ valid_check ∧ is_executable` — the majority.
  - **C2 (human-re-verified):** oracle-blind clean claims, human-adjudicated with provenance.
  - Mining from passing runs yields **candidates only**; the harness **refuses** a clean item lacking a
    C1/C2 provenance stamp.

## 4. Statistics — nested bootstrap + re-derived n (resolves CRITICAL-3, HIGH-1)

> **CRITICAL-3:** the original stats had two stacked independence violations — (a) "decompose Δ additively
> across two independent strata" ignores the **negative sens↔spec covariance** one judge induces; (b)
> "collapse R trials to a per-item score then bootstrap over items" **throws away within-item judge
> variance** (a coin-flip judge then clears Δmin with a deceptively tight CI). **HIGH-1:** the
> `Var(δ)≈0.25` power assumption was single-Bernoulli, so n=60→140 was numerology.

### 4.1 Frozen artifact
One record per `(item, trial, arm)` cell: `{item_id, stratum, arm, trial, seed, flagged, route}`.
`seed` is the **CRN pairing unit** — for a given `(item, trial)` all arms ran under the same seed.
The deterministic CI tier reads this artifact and never calls a model.

### 4.2 Nested (cluster) bootstrap
One bootstrap loop: **outer** resamples *items* (stratified, fixing per-stratum n); **inner** resamples
the *R trials within each chosen item* (folded into the same draw, CRN-shared across arms); **J is
recomputed end-to-end** for every arm on the *same* draw. Consequences:
- The inner trial-resample **reinflates within-item flip variance** → a flaky judge gets a *wide* CI
  (CRITICAL-3b closed).
- sens (K/O error items) and spec (clean) recomputed on one outer draw → the negative `Cov(sens,spec)` is
  **embedded in J's spread, never assumed 0** (CRITICAL-3a closed).
- The **shared clean stratum is resampled exactly once per outer iteration** and reused for every J that
  needs spec — resampling it separately would inject artificial independence.
- δ is formed per-resample (`J(D) − J(C)` on the same draw), mirroring `_paired_regret_deltas`
  (`test_pod_2_1_stats_spike.py:279-287`). `n_outer = 2000` (gate), 500 (fast tier). Percentile CI.

### 4.3 Variance model + the realized-Var diagnostic
`Var(δ̂) = Var_between-item + Var_within-item(R) + Cov(sens,spec) + Cov_arm(D,C)`. The harness **reports**,
not assumes:
- `ρ̂_arm = 1 − Var(δ_paired)/(Var(J(D))+Var(J(C)))` — pairing helped iff `ρ̂_arm > 0`; **assert it** (if
  ≤ 0, CRN bought nothing and the n credit is void → loud failure).
- `Cov(sens,spec)` printed with its sign (expected negative under a global judge bias).

### 4.4 Re-derived per-stratum n (Δmin = 0.15, ~80% power, one-sided α=0.05)
Per-item variance of the R-mean `σ²_item = σ²_b + σ²_w/R = 0.10 + 0.25/7 = 0.1357` (conservative,
ρ_arm=0 a-priori, Cov=0 for sizing). `n ≥ (1.645+0.842)²·0.543/0.15² ≈ **150**`.

| Stratum | Role | n (planning) |
|---|---|---|
| **K** | binding (D>A, D>C) | **~150 error items** |
| **clean** | binding (spec) | **~150 clean items** |
| **O** | reported-only null + route invariant | **~50 error items** |

≈ 350 items × R=7 ≈ 2,450 graded cells/arm, ×5 arms ≈ 12k nightly cells — feasible.
- **Δmin=0.15 is the feasible floor.** Δmin=0.10 costs ~336/stratum (likely infeasible nightly) —
  push back unless budgeted.
- **Realized-Var feedback loop (M-3 instrument check):** after the first nightly run, recompute
  `σ²_b, σ²_w, ρ_arm, Cov` from the artifact; if realized `Var(δ̂) > 0.543/n`, re-derive n **upward
  before the verdict is trusted**. Load-bearing guesses: `σ²_b=0.10`, `σ²_w=0.25` — the first run must
  confirm them or n is wrong.

### 4.5 MC-vs-`lcb` cross-check (MED-2 handled honestly)
`beta.lcb` (`beta.py:116`) is a one-sided bound on a **single Beta** (one proportion). There is **no
shipped joint-J bound** — do not claim `lcb(sens)+lcb(spec)−1` is a valid 95% J bound (mis-calibrated,
ignores Cov). The cross-check audits the **MC sampler's correctness on a single proportion** (MC 5th
percentile vs `lcb`, tolerance pinned to MC SE — mirrors `test_pod_2_1_stats_spike.py:161-177`). The
**nested bootstrap percentile CI** is the gate authority on the paired δ-in-J; the two instruments are
never substituted.

## 6. Frozen-artifact fingerprint (resolves MED-1)

> **MED-1:** no freshness binding — a prompt/router/judge-tier refactor leaves a stale green artifact
> certifying a dead system; the artifact can be cherry-picked across nondeterministic regens.

Stamp a **`MeasurementFingerprint`** into the artifact = hash over: each arm's `_SYSTEM_INSTRUCTIONS`
(`dialectic.py:427`); the per-arm info-diet code-path id (the `ContextRequest` variant); per-arm model
id/checkpoint (incl. D′'s cross-family model); the `route_dialectic` source; the `OracleRegistry` config;
the corpus content hash. The scorer **recomputes the fingerprint from current code/config and hard-refuses
to score on mismatch** — closes both stale-artifact and cherry-pick holes. Additive `MeasurementFingerprint`
frozen Pydantic model (python-expert).

## 7. The assert-the-non-win guard (resolves MED-3)

> **MED-3:** the Pod 2.1 "assert the negative so the gate can't relax" pattern is unsafe here — if the
> *measurement* is broken it reports "D adds nothing" even when D is excellent, ships oracle-only, and
> locks in the artifact.

The assert-the-non-win **arms only after** the instrument passes its own validity controls (all on the
same harness/artifact):

| Control | Construction | Passes iff | Fails (loud) iff |
|---|---|---|---|
| **Positive (known-strong)** | synthetic oracle-perfect detector | `J_pos` CI lower bound **> 0.8** | LB ≤ 0.8 → J computation broken |
| **Negative / always-broke** | yes-machine (flag everything) | `spec LCB < 0.1`, `J_neg ≈ 0` | `J_neg` LB > 0 → specificity not biting (J gameable by flag-spam) |
| **Negative / never-flags** | flag nothing | `J ≈ 0` | `J_neg` > 0 → sens arm broken |
| **Stratum-O null** | D vs A on O | `\|δ_DA^O\|` CI within ±Δmin (TOST) **and** O-flags oracle-routed | CI excludes band, or O-flags antithesis-routed |

If any control fails → result is **"instrument invalid — re-measure,"** never "D adds nothing."

## 8. Mutation-resistance (the red-team will mutation-test these)

Robust **signs/orderings over fragile magnitudes** (`test_pod_2_1_stats_spike.py:338-361`):
1. Gate on `delta_lo > 0` and orderings `J(D)>J(C)>J(B)`, `J_pos>J(D)>J_neg` — survive jitter, break on regression.
2. **Degenerate pins (must FAIL the gate):** yes-machine → spec LCB fails; **coin judge** Bernoulli(0.5) →
   J CI **contains 0** (mutating away the inner nest makes it spuriously tight → caught); **3/7-vs-7/7 flake**
   → δ CI does **not** clear 0.15 despite J≈0.2 point estimate.
3. **Bootstrap-urn-size pins:** outer urn size **= item count, not item×R**; clean pool resampled **once**
   per outer iteration (counter == n_outer).
4. **Pairing-reduction pin:** `ρ̂_arm > 0`, and an unpaired δ (J(D), J(C) on *different* draws) yields a
   strictly wider CI.
5. **Covariance-sign pin:** `Cov(sens,spec)` reported; under an injected global-bias judge it is negative.

## 13.1 CodeOracle self-test laundering (was NEW HOLE #1 — CRITICAL, S9)

**The open path:** `CodeOracle` extracts BOTH the solution and the test from model-authored thesis fields
(`oracles/code.py:328-329`); pytest returncode 0 → `source="tool"` → `is_executable=True`
(`contracts.py:103`) → `evidence_projector.py:117` mints a **`confirmed`** Claim over the model-authored
`verifiable_claim`. A thesis writing `def test_x(): assert True` mints `confirmed` truth. The 4.3 spike
*blesses* this (`test_pod_4_3_dialectic_spike.py:884-893`). The revision-1 INV-3 guarded the **already-closed**
antithesis path (OB-PROV hardwire `dialectic.py:515`; `verdict_from_antithesis` always `inference`,
`outcome.py:120`) — it spent its budget on a closed door.

**Gate-corpus fix (ruled):**
- **Corpus-author-frozen tests.** Add a `CodeOracle` `test_source: Literal["thesis","frozen"]` selector
  (additive, default `"thesis"` → shipped behavior unchanged). Gate-corpus O- and C1-clean items carry an
  author-frozen `test_code`; the eval runner binds a CodeOracle that sources `test_code` from the **corpus
  item**, `solution_code` from the model's thesis. "First-hand tool verification" now grades a model
  solution against an **independent** test. *(python-expert owns the signature.)*
- **INV-3 splits in two:** **INV-3a** (test-provenance) — every `confirmed` Claim in the gate run must be
  backed by a CodeOracle invocation tagged `test_source=="frozen"`; a `confirmed` Claim from a
  `test_source=="thesis"` invocation **fails the gate**. **INV-3b** (the kept corpus-wide assertion) — no
  `inference`/model-antithesis item mints `confirmed`, asserted on the Claim node.

**Shipped-system ruling (escalates beyond the gate → Jim): this is a real S9 defect, not an accepted
design point.** The `confirmed` Claim is minted off the experiment/oracle step *before* the antithesis
speaks, and the antithesis only has BROKE→REFINE leverage — it **cannot revoke** an already-minted
`confirmed` node, so "caught downstream" is false. Recorded as **CF-4.4-CODEORACLE-SELFTEST** (see §13.8).

## 13.2 C′ measurement arm un-deferred (was NEW HOLE #3 — HIGH)

The revision-1 C (final-answer-only diet) is a **capability-confounded strawman**: D reads the trajectory,
C cannot, so D>C measures "trajectory access catches trajectory errors" (near-tautological), not "the
adversarial design is good." **Ruling: add C′ = neutral framing + trajectory-access diet** (identical info
diet to D, differs only in framing — a measurement control, not a shipped arm). Revised binding comparisons
**on K**: **D > A** (causal contribution over the oracle floor) and **D > C′** (the *adversarial framing*
contribution over a neutral arm with identical trajectory access). **D > C is demoted to reported-only**
(the bundled, tautological comparison). Cost: ~+2,100 cells/nightly (Jim budget, §13.8).

## 13.3 O-stratum → one-sided non-inferiority (was NEW HOLE #4 — HIGH; §2/§7 contradiction)

Revision-1 §2 said "D not-worse-than-A" (one-sided) but §7 implemented two-sided TOST — vacuous at n=50.
**Ruling:** the O-control becomes a **one-sided non-inferiority** bound — `δ_DA^O` lower CI bound > `−m_NI`
(D not materially worse than the oracle floor by over-flagging oracle-decided items) **AND** O-flags
oracle-routed. Delete the "D≈A pre-registered null." eval-stats sized it (§13.6): **m_NI = 0.05, n_O = 70**.

## 13.4 Fingerprint + correlated-clean + positive-control (was NEW HOLES #5/#6/#7 — MED)

- **#6 MeasurementFingerprint:** hash **semantic** identifiers (whitespace-normalized prompts, sorted

## 13.5 Minimal binding core (was CROSS-CUTTING erosion risk)

~12 conjunctive green conditions on a nondeterministic nightly → dies by erosion. **Ruling: a small core
gates; the rest is reported-but-reviewed (non-blocking).**

**Binding core (these and only these block the gate):**
1. **J(D) > J(C′) on K**, paired nested-bootstrap δ CI lower bound > 0 (the adversarial-contribution claim, isolated).

## 13.6 Statistics revision 2 (supersedes §4.4 sizing)

**The revision-1 `n≈150` is WITHDRAWN.** Its `0.543` was `4·σ²_item` — a magic constant stacking three
unstated assumptions, using a per-item *score* variance (borrowed from the Pod 2.1 regret bootstrap) where
the gated statistic needs a *proportion* variance (`p(1−p)`), on mismatched populations (sens on K, spec on
clean — different n's).

- **Correct variance object:** `Var(δ_DC)` = two-stratum, CRN-paired **proportion** variances, each with a
  between-item term (`σ²_b/m`, CRN-reduced by ρ_b) and a within-item term (`E[p(1−p)]/(R·m)`). **No factor
  of 4.** On K, arm A flags nothing (`sens_A≡0, spec_A≡1`), so `δ_DA^K = J_D` — A adds no variance and n_K
  is governed by the harder `δ_DC` test. The shared-clean positive covariance **does not enter** the binding
  n because strata are scored separately, never pooled.
- **Re-derived n** (Δmin=0.15, 80% power, one-sided α=0.05; planning inputs: mean sens 0.60 / spec 0.85,
  σ²_b,sens=0.020, σ²_b,spec=0.010, ρ_b=0.5, ρ_w=0.3): honest minimum **m≈30/stratum**; **recommended
  n_K = n_clean = 80** (a deliberate ~3.2× variance headroom against the soft σ²_b guesses), **n_O = 70**
  (one-sided NI at margin m_NI=0.05). Nightly cells drop from ~12k to ~7,350. *Holding 150 is fine but
  over-powered; the derivation supports 80.*
- **Pre-nightly simulation gate (breaks the circularity):** a deterministic CI-tier test runs the **exact
  §4.2 nested bootstrap** on **synthetic data from the planning variances** and requires
  `power_lcb = beta.lcb(clears+1, N−clears+1, 0.05) ≥ 0.80` at the proposed n, plus a true-null companion
  (`dsens=dspec=0` → `power_lcb ≤ 0.10`, proves the test can fail) and an under-power tripwire (n=30 can
  fail, n=80 cannot). The §4.4 realized-Var loop then re-runs the *same* test on *measured* variances after
  run 1. **The sizing-test generator (`synth_cells`) and the gate's `nested_bootstrap_delta` MUST share the
  exact `Cell` schema + resampling code** (pin with a shared-function assertion in 4.4a) — else the
  pre-nightly verification proves nothing about the gate.
- **Label-shuffle control (gate-binding):** permute ground-truth labels (≥20 seeded shuffles), recompute J
  via the same bootstrap; require **every** shuffle's CI to contain 0 **and** `|mean(shuffle_J)| < 0.05`.
  The two assertions fail on opposite mutations (remove-the-shuffle vs widen-the-CI), so passing requires
  genuine no-leakage. Pure deterministic CI-tier work on the frozen artifact.
- **Honesty caveat (eval-stats):** the pre-nightly sim verifies the *estimator's* power **if** the world
  matches planning; it does **not** verify the world matches planning — only run-1 data does. Keep both the
  sim and the realized-Var re-check; the sim does not make the post-nightly check redundant.
