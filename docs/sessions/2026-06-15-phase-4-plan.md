## What Phase 4 is

The **S9 capstone.** Phases 1–3 built a loop that thinks, remembers, and acts safely; none of it
answers *"is the answer actually right?"* without trusting the model's say-so. Phase 4 supplies the
**external, structural ground-truth signal** S9 demands ("never trust the model's self-report; require
external/structural signals") and the **dialectical check** that turns it into a routed decision.

Depends on Phases 1–3 (all VALIDATED): cyclic journaled pathways + `AwaitHuman`/`Degraded` (Phase 1),
the off-path trial-projection seam + entity-KG evidence + coherence (Phase 2), the model ladder +
context assembly + the durable `ToolGate`/taint latch + the budget guard (Phase 3).

**Port sources** (on disk under `C:/Users/Jim/OneDrive/Desktop/Code/`): `tess` (oracle layer +
thesis/antithesis stages + honest-failure) and `bizzy/biz-firm` research (E1 external-signal
requirement; F2 antithesis-as-adversarial-eval + judge biases; F4 error taxonomy; a3 debate

## Central design principle (unchanged — survived review)

**Compose, don't hardcode.** tess ships a monolithic 10-stage `OuterLoop`; cog-worx ships the dialectic
as **composable `Stage` primitives + a reference pathway** (the `reference_agent.py` pattern), per CANON
§0.5 ("config over code — developers author their own pathways"). The 4-stage grain
(Thesis → Experiment → Antithesis → Evaluate) was *confirmed* the right grain by `architect`. The
`EvaluateStage`-as-pure-code-router boundary (model proposes, code decides "am I done") was confirmed
correct — F2 kills only the *claim* that pure-code routing makes the decision self-report-free, not the
boundary itself.

Phase 4 remains **mostly additive** on frozen seams — **with one exception the first draft missed**: the
upstream-artifact accessor (F5). No new `StageResult` kind is needed (verified: the five —
`Transition`/`Done`/`AwaitHuman`/`Degraded`/`Wait`, `result.py:79-82` — cover the full tess NextAction
set {DONE, REFINE, REFRAME, ESCALATE}). No new durability primitive for the *path* (per-visit
`step_index`, `journal.py:8-9`). The dialectic's **substrate consequences** are projected **off-path**
(S1) — but as a *distinct* event stream with *honest* provenance (F1), not a free ride on the Pod 2.1
trial projector.

## Revised pod plan (dependency-ordered: 4.0 → {4.1 ∥ 4.2} → 4.3 → 4.4)

### Pod 4.0 — Oracle seam + verdict contracts + registry + the upstream-read seam *(foundational)*

The external-signal substrate. Everything in the phase verifies against it.

**Deliverables**
- **`Oracle` protocol** — `async evaluate(*, frame, thesis, ctx) -> Verdict`. A **distinct seam**, not
  folded into `Capability` (a `Capability` is a permission-tiered, `Any`-returning tool; an oracle
  returns a typed, epistemically-privileged verdict). It **composes** the Pod 3.2 capability registry
  for tool-backed checks (mirrors "3.1 context composes, not subsumes, 2.6"). *(architect, high
  confidence — port tess `oracle.py`.)*
- **`Verdict`** — `{holds: bool, valid_check: bool, reasoning: str}` (port tess `ExperimentTrial`'s
  load-bearing three fields, `artifacts.py:235`). `valid_check=False` = the honest "this didn't
  actually test anything" bit (timeout / no tests collected / tool threw); **it gates the downstream
  Beta update** so noise can't bias the posterior.
- **`OracleRegistry`** — `resolve((completion_criterion, problem_type))`, **exact → wildcard →
  always-on fallback, never raises** (S8 degradation). Port tess's always-wired fallback
  (`oracle.py:62-73`) so resolution is total.
- **F5 — the upstream-read seam (NEW, needs Jim).** Add an additive `StageContext` accessor —
  `async def last_output(self, stage_name: str) -> Artifact | None` (or `outputs_since`) — backed by
  `journal.load_run` (the same pull-from-journal idiom as `read_human_input`, `stage.py:66`). Without
  it `EvaluateStage` cannot read the oracle/antithesis verdicts it routes on; the engine threads **no**
  artifact between stages (the `initial: Artifact` param at `engine.py:444` is dead). It is a **new
  Protocol member → C3-class contract change**, exactly like the Jim-approved 3.1e `assemble_context`
  / 3.2c additions. The accessor must be **cycle-aware** (select the verdict of *this* refine cycle —
  the most recent committed `antithesis` step strictly after the most recent `thesis` step) and
  **crash-correct** (after a mid-cycle resume the walk sees a complete prior cycle + a partial current
  one). *(architect R1.)*
- **F1/F9 — honest provenance for verification outcomes.** Reuse `source="tool"` + the **evidence
  types already shipped for this phase** — `evidence.py:29-60` pre-provisions `refutation` (weight 3.0,
  polarity −) and `antithesis_survival` (weight 1.5), dead code today, planted for Phase 4. Plus
  `tool_proof` (weight 3.0) for executable-oracle verdicts. **Do NOT add an `'oracle'` member to the
  `ProvenanceSource` `Literal`** (`provenance.py:22`) — that breaks every exhaustive reader under mypy
  `--strict` (same hazard class as adding a Protocol member; CANON §6.1 is *silent* on Literal-member
  additions but the exhaustiveness break makes it breaking). Keep the **provenance** question
  (`source`, on the `Claim`) separate from the **evidence-type** question (truth-weight, on
  `EvidenceEvent.type`) — the first draft conflated them.
- **F8 — S10 quarantine.** Add a **model-output quarantine channel** (nonce-tagged BEGIN/END markers,
  port tess `_shared.py`) for thesis output entering the antithesis — this is genuinely new surface
  (thesis output is model-generated, won't trip the existing external-tier taint trigger). **Do not
  rebuild** the durable taint latch — it already exists (`capability/policy.py`, Pod 3.2). **Declare
  CF-3.2-B a precondition** (untagged read-tier ingestion doesn't taint/wrap — the same way Pod 2.3's
  source registry was a precondition for 2.0); the marker is defense-in-depth, never the primary
  defense (S10).

**Spike:** the upstream-read accessor returns the correct cycle's artifact across a mid-cycle resume;
verdict is structurally ground-truth-typed (no oracle path emits an `inference`-typed *confirmed*
correctness claim); registry degrades to fallback under a lesioned oracle; the model-output quarantine
round-trips and integrates with the existing taint latch.

### Pod 4.1 — Concrete oracle suite *(after 4.0; sub-pods independently lesionable)*

- **4.1a — Deterministic-code oracle (load-bearing).** Subprocess `pytest` (port `pytest_runner.py`):
  exit-code → `(holds, valid_check)`, hard timeout + process-group kill, scrubbed env, fresh tempdir.
  **F7 — bind the sandbox tier to the taint bit.** tess's own runner is blunt: *"this is NOT a security
  sandbox"* (unrestricted network; Windows `CTRL_BREAK` group-kill is *cooperative* — a detached/
  double-forked process survives). Since the oracle **executes model-written code**, the moment a drive
  is tainted that code is adversary-influenced. So: the **docker-hardened tier** (`--network none`,
  mem/pids/cpu caps, `--cap-drop=ALL`, read-only, non-root — port `docker_pytest_runner.py`) is **bound
  structurally to `RunState.tainted`** — the unsandboxed subprocess tier **refuses** to run model code
  on a tainted drive. *(red-teamer Attack 5 — revises the first draft's "docker is pure opt-in.")*
- **4.1b — Math oracle.** sympy / `decimal` exact-arithmetic (modest dep).
- **4.1c / 4.1d — Chemistry (RDKit) / Physics (pymunk).** **Optional extras** (`cogworx[chemistry]`,
  `cogworx[physics]`), lazy-imported, **lesion-clean when absent** (S8: missing dep → registry
  fallback, never an import crash). Matches the shipped `cogworx[mcp]` pattern. *(Scope: ship both
  behind extras in v1 — see Decisions.)*

**Spike (each):** correct verdict on a known-good/known-bad fixture; `valid_check=False` on a
non-test; S8 lesion — dep/engine absent → degrade, the run completes honestly-labeled. **Per the
test-hang discipline: each subprocess/docker oracle spike is a single `timeout`-wrapped file; never
joined to the full `tests/spike` tier (known cross-test resource leak).**

### Pod 4.2 — Honest failure *(parallel with 4.1, after 4.0)*

"Admit it, don't confabulate" — a mapping onto existing seams + a classifier, not new machinery.

- **Typed abstention** — a thesis may return an honest *"I cannot establish this"* (null verifiable
  claim) rather than a confident fabrication; the antithesis's **`could_not_break` is equally valued**
  (port the enum + cross-field validators that *structurally* forbid a "broke" verdict with no
  breakage).
- **Error taxonomy (port biz-firm F4)** — classify **transient | permanent | degraded** *before*
  retrying; feed the existing Pod 1.2 `RetryPolicy` (retrying a permanent error — hallucinated tool
  name, schema mismatch — is the most damaging waste).
- **Routing onto existing results** — abstain/stuck/cost → **`AwaitHuman`** (durable HITL, Pod 1.3);
  unverifiable → **`Degraded`**; `could_not_break ∧ oracle-pass` → **`Done`**. **No new `StageResult`
  kind** (confirmed). **S11 watch:** the cost-ceiling path routes a *budget-guard* trip to HITL — the
  dialectic must not self-terminate on cost (the budget guard is the structural trigger).

**Spike:** the abstention path is discriminable from a confident answer; the taxonomy routes each class
correctly; over-budget/stuck escalates to `AwaitHuman` rather than looping.

### Pod 4.3 — Thesis/antithesis team decision-making *(integrative — depends on 4.0 + 4.1a + 4.2)*

The dialectic as composable stages on the existing graph/FSM loop.

**Deliverables**
- **`ThesisStage`** (propose) → **`ExperimentStage`** (calls the oracle) → **`AntithesisStage`**
  (adversarial challenge) → **`EvaluateStage`** (deterministic route) + a **reference dialectical
  pathway** in the Test Kit. The pathway author must get the `transitions` tuples exact (the
  `StageGraph` validator requires reachability + a reachable terminal, `graph.py:69-77`).
- **Structural independence (S9).** The antithesis runs in a **fresh, isolated context** and does NOT
  see the thesis's chain-of-thought; thesis output enters via the 4.0 quarantine. The cleanest way to
  *guarantee* isolation on our seam is the **per-stage `context_policy`** (`bind_context_policy`,
  3.1e) assembling a context with the thesis *artifact* (proposed solution, experiment design) but no
  reasoning/CoT. "Separate model instance" is secondary; the load-bearing thing is the **context
  boundary**.
- **F2 — the honest S9 boundary (load-bearing redesign).** Routing is pure code, but **its inputs are
  not all ground truth.** The antithesis `verdict`/`severity` are *model self-reports*, and (per tess
  `_stage_8_evaluate`) `severity` can drive a REFRAME even over an oracle pass. So:
  - When an **executable/deterministic oracle** produced the verdict, S9 is satisfied — route on it.
  - When the **LLM-judge fallback** produced it (every non-executable criterion), the verdict is a
    model self-report; the model-antithesis is a **heuristic prioritizer, not a verifier.** It may
    raise priority for refinement but **must not, by itself, emit a confident "verified"** outcome.
  - **State this honestly in the plan and the code** — do not claim routing is self-report-free in
    general. *(red-teamer Attack 1.)*
- **F1 — dialectic outcomes are a DISTINCT off-path event stream (load-bearing redesign).** The
  `EvaluateStage` stamps an outcome for off-path projection (S1), **but**:
  - The existing `TrialProjector._trial_provenance` hardcodes `source="system", confidence=1.0`
    (`projector.py:246`) and `resolve_outcome` *raises* without a registered `procedure_id`
    (`projector.py:132`). It projects **procedure** trials, not **verification verdicts** — a different
    stream.
  - So: a **separate verification-evidence projector** (sweeper-shaped, off-path) writes the
    `refutation` / `antithesis_survival` / `tool_proof` evidence to the entity KG, with provenance a
    **function of the verdict's source** — `tool`/`system` for an executable oracle, **`inference` for
    a model-judge verdict, never `confidence=1.0`.**
  - **Stamp an outcome for the procedural-KG Beta only on `valid_check=True` AND an executable-oracle
    source.** An invalid or model-judge-only experiment routes to refine and stamps **nothing** — which
    keeps the Pod 2.1 projector untouched *and* the posterior honest. *(architect R3 + red-teamer
    Attack 2.)*
- **F6 — loop state derived-at-read, with a hard ceiling.** The refine loop's accumulator (cycle
  index, breakage history, Jaccard stuck-detector inputs) is **recomputed from committed `antithesis`
  steps every visit, never carried in memory** (a fresh stage instance after a crash-resume has zero
  in-process state; per-visit `step_index` replays the *path*, not the accumulator). Mirrors the Pod
  2.1 derive-at-read posterior. Plus a **hard per-loop cycle ceiling** (tess `MAX_ITERATIONS=5`) that
  escalates to `AwaitHuman` at cap — lives in `EvaluateStage` routing, not the global `max_steps`
  guillotine. *(architect R2.)*
- **F2 (trajectory) upgrade over tess** — the antithesis checks the **trajectory** (tool calls,
  intermediate steps), not just the final answer (SIRAJ — ~2–2.5× vulnerability coverage). v1 is a
  **single dialectical pair** (a3 echo-chamber + cost rule out an N-agent panel now — confirmed by
  architect).

**Spike:** the loop converges on a planted-correct thesis and refines a planted-flawed one; routing is
provably model-free *given its inputs*; the dialectic-evidence projector writes `inference`-typed
evidence for model-judge verdicts and `tool`-typed for executable ones (no laundering); **a
kill-mid-refine-cycle resume reconstructs the accumulator correctly and re-runs with no model re-call**
(S6). *(architect R5 — the crash-correctness of the journal-walk is the thing most likely to be
silently wrong.)*

### Pod 4.4 — ⛓ GATE Spike *(after all)*

The first draft's gate was **rigged and underpowered** (F3) and blind to the correlated blind spot
(F4). The redesign, grounded in the Pod 2.1 stats precedent and eval-stats discipline:

**1. Antithesis catch-rate eval — joint criterion, real ablation, real power.**
- **Statistic — joint, not single.** Two independent Beta posteriors on disjoint fixture strata:
  **sensitivity** `Beta(1+TP, 1+FN)` over planted-error items; **specificity** `Beta(1+TN, 1+FP)` over
  clean items. Headline **Youden's J = sens + spec − 1** (J=0 for both "always-broke" and
  "always-pass"); **gate on both arms separately.** A single detection rate can't catch the degenerate
  "cry-broke-on-everything" antithesis (sens→1, spec→0). Use the shipped `beta.lcb` — **no scipy**
  (S2).
- **Comparator — 4-arm ablation, not a strawman.** A oracle-only · B single-pass self-check · C
  neutral second look (fresh instance, "review this," no CoT) · D adversarial antithesis · **D′
  cross-family antithesis (F4).** "Non-overlap vs self-check" is the exact mistake Pod 2.1 deprecated
  in code (`test_pod_2_1_stats_spike.py:297-311` — beating a known-weak baseline justifies nothing).
  **The gates that matter: D beats C** (does the adversarial framing earn its keep over a second look?)
  **and D beats A** (does the model antithesis beat the oracle floor it would replace?).
- **Fixture — break the author-bias loop (F3).** Errors planted by a **different agent** than the
  antithesis author; **held-out error categories** (tune the prompt on a disclosed subset, measure on
  held-out); **naturalistic errors mined from real Phase 1–3 failed-run journals**; ground-truth
  labeled by **oracle/human, never the judge**. Cover: factual/ground-truth-contradiction, logical
  invalidity, constraint violation (oracle-checkable), spec-noncompliance, numerical/unit, over-claim —
  plus a clean stratum and a subtle/blatant severity axis. **Enforce the antithesis's information diet**
  — strip answer-bearing artifacts (port tess `judge_calibration.py:149` — seeing the test source is
  comprehension, not prediction).
- **Power.** **≥60 items/stratum (≥120 total), R=5–10 fixed-seed trials/item, paired across arms**
  (Pod 2.1 common-random-numbers). **avg@N is over items**; R captures judge variance. Pre-register the
  effect size: **D must beat C and A on Youden's J by ≥ Δmin=0.15**, paired CI entirely above 0 — *not*
  merely "non-overlapping." (N≥5 was ~40× under.)
- **Bias controls.** "Fresh instance, distinct prompt, no CoT" are necessary; the dominant
  unaddressed bias is **self-preference / shared-weights collusion** when thesis = antithesis model
  (F4) → the **D vs D′ cross-family gap is a first-class spike output.** Specificity arm catches the
  verbosity/over-flagging bias.
- **The load-bearing unproven claim:** the model-antithesis beats a neutral second look *and* the
  oracle floor with non-overlapping paired CIs ≥ Δmin. **If it fails → ship oracle-only verification,
  defer the model-antithesis** (the "ship greedy, defer Thompson" precedent, Pod 2.1). With the 4-arm
  design a *negative* result is now **interpretable** (antithesis adds nothing) rather than ambiguous
  (underpowered). **Assert the non-win in code** so a future refactor can't relax the gate back to the
  strawman.

**2. Never-trust-self-report invariant (S9) — mechanical, both directions.** Routing is a pure function
of (executable-oracle ground truth + enum/structural signals), provably independent of any model
self-confidence field. Property test mirrors the Phase 2 `_FailOnCallModel` structural guard
(`test_phase2_gate_recall.py:656`): wire the antithesis confidence field to a tripwire → routing output
is byte-identical across its full range. **Add the hard direction the first draft missed (F2):** a
confident `could_not_break` with **no executable oracle** must **not** yield a confident
"verified"/`confidence=1.0` outcome. *(Note: the existing `assert_control_independent_of_model_text`,
`invariants.py:457`, is blind to the correlated-blind-spot failure — it varies only free text while
holding the routing-relevant verdict fixed — so it does NOT substitute for the F4 cross-family arm.)*

**3. + S8 lesion** (oracle suite off → loop completes honestly-unverified) **+ S10** (quarantine + taint
round-trip; tainted-drive code refuses the unsandboxed tier, F7) **+ red-team pass** before "VALIDATED"
(per the `redteam-before-validated` rule).
